# Knn-classroom

แบ่งกลุ่มหน้าเพื่อนในห้องจากรูปใน `dataset/` ด้วย **PCA + K-means**
แล้วบอกว่าแต่ละกลุ่มมีลักษณะอะไรที่ต่างจากคนอื่น ใช้แค่ OpenCV กับ NumPy

> ชื่อ repo มาจากเวอร์ชันแรกที่ใช้ KNN จดจำหน้าผ่านกล้อง ตอนนี้เหลือเฉพาะการแบ่งกลุ่มจาก dataset
> ไม่มีการเปิดกล้อง และไม่มีการบันทึกไฟล์ใด ๆ

## ไฟล์ในโปรเจค

| ไฟล์ | หน้าที่ |
|---|---|
| `face_utils.py` | อ่านรูปใน `dataset/` หาหน้าแล้วตัดเฉพาะหน้า |
| `cluster.py` | แบ่งกลุ่มหน้าด้วย PCA + K-means บอกเกณฑ์ของแต่ละกลุ่ม แล้วแสดงภาพผล |
| `dataset/` | รูปนักเรียน 32 คน คนละ 1 รูป |
| `requirements.txt` | ไลบรารีที่ต้องติดตั้ง (OpenCV เวอร์ชัน 4 + NumPy) |

## ติดตั้ง

ทดสอบกับ Python 3.14, OpenCV 4.14, NumPy 2.5

```bash
pip install -r requirements.txt
```

> ต้องใช้ **OpenCV เวอร์ชัน 4** (`opencv-python<5`) เพราะ OpenCV 5.0 ถอด `cv2.CascadeClassifier` (Haar Cascade) ออกแล้ว
> ถ้าติดตั้ง 5.0 ไปแล้ว ให้รัน `pip install "opencv-python<5"`

## วิธีใช้

1. ใส่รูปไว้ใน `dataset/` ตั้งชื่อไฟล์เป็น `รหัส_ชื่อ.jpg` เช่น `6752300046_Taer.jpg`
   - 1 คนมีหลายรูปได้ เช่น `6752300046_Taer_2.jpg` (ระบบใช้หน้าเฉลี่ยของคนนั้น)
   - รองรับ .jpg .png .bmp .webp ส่วน .heif (รูปจาก iPhone) ต้องแปลงเป็น .jpg ก่อน
   - รูปที่อ่านไม่ได้หรือหาหน้าไม่เจอ และไฟล์ที่ไม่ใช่รูป จะถูกข้ามและแจ้งชื่อไฟล์ในหน้าจอ
   - ถ้ารหัสหน้า `_` ไม่ใช่ตัวเลข 10 หลัก จะมีคำเตือนให้ตรวจชื่อไฟล์
2. เปิด terminal ในโฟลเดอร์โปรเจคแล้วรัน (ถ้าไม่เจอคำสั่ง `python` ให้ใช้ `py cluster.py`)
   หรือเปิด `cluster.py` ใน VS Code แล้วกด ▶ Run

```bash
python cluster.py
```

3. รอสักครู่ (อ่านรูปทั้งหมดก่อน) แล้วจะเห็นผล 2 แบบ
   - **ใน terminal**: silhouette ของแต่ละค่า k, สมาชิกและเกณฑ์ของแต่ละกลุ่ม, คู่ที่หน้าเหมือนกันที่สุด
     ```
     silhouette: k=3 0.188, k=4 0.171, k=5 0.170, k=6 0.155 -> ใช้ 3 กลุ่ม

     กลุ่ม 1 (11 คน): Taer, Kang, Mew, jimmy, Phai, ...
        เกณฑ์: มีผมคลุมข้างแก้ม (ผมยาว) [z=-0.90], ไม่ค่อยมีคนใส่แว่น [z=-0.59]
     ```
   - **หน้าต่างรูป**: 1 แถว = 1 กลุ่ม เรียงเป็น ชื่อกลุ่ม (Group 1, 2, 3) → หน้าเฉลี่ยของกลุ่ม (average) → สมาชิกพร้อมชื่อ
     คลิกที่หน้าต่างแล้วกดปุ่มใดก็ได้เพื่อปิด

## ตั้งค่า (ด้านบนของ `cluster.py`)

| ค่า | ปัจจุบัน | ความหมาย |
|---|---|---|
| `N_PCA` | `10` | ย่อข้อมูลเหลือกี่มิติก่อนจัดกลุ่ม |
| `K_CHOICES` | `range(3, 7)` | จำนวนกลุ่มที่ให้ลอง แล้วเลือกค่าที่ silhouette สูงสุด ถ้าอยากได้ 5 กลุ่มพอดี ให้แก้เป็น `range(5, 6)` |

## หลักการทำงาน

### 1. ตัดหน้า (`face_utils.py`)

รูปใน dataset ถ่ายมาไม่เหมือนกัน บางรูปเต็มตัว บางรูปชิดหน้ามาก ถ้าเอาทั้งรูปมาเทียบ
ระบบจะแบ่งตาม "ระยะถ่าย" แทนที่จะเป็น "หน้า" จึงต้องตัดให้ทุกรูปเป็นแบบเดียวกันก่อน

1. ตัดกรอบแดงที่ติดมากับบางรูปออก
2. หาหน้าด้วย Haar Cascade (มากับ OpenCV)
3. ตัดเฉพาะช่วงหน้าผากถึงคาง แก้มถึงแก้ม แล้วย่อเป็นภาพขาวดำ 140×180
4. ปรับแสงให้เท่ากัน (`equalizeHist`) แล้วแปลงเป็นเวกเตอร์ 25,200 ค่า

### 2. แบ่งกลุ่ม (`cluster.py`): ใช้อะไรแบ่ง

**อัลกอริทึมที่ใช้แบ่ง**

1. **PCA** ย่อเวกเตอร์ 25,200 ค่า เหลือ 10 มิติที่สำคัญที่สุด (eigenfaces) เพื่อลด noise
2. **K-means** จัดคนที่อยู่ใกล้กันในพื้นที่ 10 มิตินี้ไว้กลุ่มเดียวกัน = หน้า (ทั้งภาพ) คล้ายกัน
   ใช้ k-means++ และ seed 42 ให้ผลเหมือนเดิมทุกครั้ง กลุ่ม 1 คือกลุ่มที่มีคนมากที่สุด
3. **Silhouette score** ใช้เลือกจำนวนกลุ่ม โดยลอง k = 3–6 แล้วเลือกค่าที่สูงที่สุด
   (ยิ่งสูง = แต่ละกลุ่มแยกจากกันชัด)

| k | 3 | 4 | 5 | 6 |
|---|---|---|---|---|
| silhouette | **0.188** | 0.171 | 0.170 | 0.155 |

→ เลือก **3 กลุ่ม**

**เกณฑ์ที่ใช้อธิบายแต่ละกลุ่ม**

K-means ไม่ได้ใช้เกณฑ์ที่ตั้งไว้ล่วงหน้า มันแบ่งตามความเหมือนของภาพเท่านั้น
เพื่ออธิบายว่าแต่ละกลุ่มต่างกันตรงไหน จึงวัดลักษณะที่เข้าใจได้ 5 อย่างจากทุกหน้า

| ลักษณะ | วัดจาก |
|---|---|
| สีผิว / แสง | ความสว่างเฉลี่ยของแก้มกับจมูก |
| ผมบังหน้าผาก | ความสว่างของหน้าผากเทียบกับแก้ม (มืด = มีผม/หน้าม้า) |
| ผมคลุมข้างแก้ม | ความสว่างของขอบซ้ายขวาเทียบกับแก้ม (มืด = ผมยาว/ผมปรก) |
| แว่นตา | เส้นแนวนอนตรงสะพานจมูกระหว่างตา (สะพานแว่น) |
| ความคมชัดของภาพ | ส่วนเบี่ยงเบนมาตรฐานของค่าพิกเซล |

จากนั้นเทียบค่าเฉลี่ยของกลุ่มกับค่าเฉลี่ยทั้งห้อง เป็นหน่วย SD (ค่า z)
ลักษณะไหนต่างเกิน 0.5 SD จะนับเป็นเกณฑ์ของกลุ่มนั้น (z บวก = มากกว่าค่าเฉลี่ยห้อง, z ลบ = น้อยกว่า)

| กลุ่ม | สมาชิก | เกณฑ์ของกลุ่ม |
